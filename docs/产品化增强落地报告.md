## 二、增强 A:制度版本与生效期管理

### 2.1 能力

- **制度元数据**:文件编号(doc_no)、制度名称、生效日期、失效日期、状态(现行/已被替代/草案/已失效)、发布部门、适用部门、替代关系(本文件替代的编号);
- **状态自动判定**:综合状态字段与生效/失效日期,自动得出「现行有效 / 尚未生效 / 已失效 / 已被替代 / 草案」;
- **替代联动**:新版本声明「替代 HR-2023-001」后,旧版本自动标记为「已被替代」并记录被替代关系;
- **检索过滤**:问答与冲突检测默认**排除已废止/未生效版本**,避免用旧制度回答新问题;
- **版本链**:按生效日期从旧到新列出同一制度的所有版本及其状态、替代关系;
- **到期提醒**:`GET /api/doc/expiring?days=30` 列出即将到期的现行制度(前端系统页展示);
- **冲突分类**:同一制度不同版本被判定为「制度版本差异」并给出**建议依据的现行版本**;不同来源的规定矛盾则判为「跨来源规定冲突」并要求并列陈述。

### 2.2 实测证据

| 验证项 | 实测结果 |
|---|---|
| 制度元数据写入 | 编号 HR-2025-001 · 生效 2025-01-01 · 状态 现行有效 |
| 旧版自动标记 | HR-2023-001 → superseded(被 HR-2025-001 替代) |
| 版本链顺序 | HR-2023-001 → HR-2025-001(按生效日期) |
| 检索命中来源 | 年假制度2025.txt |
| 冲突分类 | 版本差异 2 处 / 跨来源冲突 0 处 |
| 建议依据版本 | HR-2025-777(生效 2025-01-01) |

> 关键效果:提问「公司年假有几天?未休完可以结转吗?」时,**已废止的 2023 版不再被检索**(命中来源仅 2025 版),回答直接依据现行版本给出 8 天/可结转;若两个库分别存有新老版本,系统会明确告知这是**版本差异**并指出现行版本编号,而非把两套说法混为一谈。

## 三、增强 B:部门/角色权限隔离

### 3.1 能力

- **知识库可见范围**:`all`(全员)或 `restricted`(仅指定部门,如 薪酬制度仅人力资源部);
- **身份传递**:请求头 `X-Actor-Role` / `X-Actor-Dept` / `X-Actor-Name`(中文部门名自动百分号编解码);
- **全链路鉴权**:知识库列表、自动路由候选、手动指定检索、跨库冲突检测、文档列表/上传/更新/删除/下载,以及库设置修改均按身份校验;
- **越权处理**:问答返回 `denied` 事件并给出明确原因;接口返回 403;同时写入审计日志;
- **前端身份切换**:侧栏可切换角色/部门,实时影响可见库与问答结果。

### 3.2 实测证据

| 场景 | 实测结果 |
|---|---|
| 受限库对非授权部门 | 隐藏(知识库列表 hidden_count=1,路由候选不含该库) |
| 受限库对授权部门 | 可见且可正常问答(命中医保/薪酬条款并给出引用) |
| 管理员身份 | 可见全部知识库(含受限库) |
| 手动指定越权库 | 拒绝 |
| 越权访问文档接口 | HTTP 403 |
| 越权调用冲突检测 | HTTP 403 |

> 越权提示示例:`无权访问知识库「_验证-薪酬制度(受限)」(可见范围:restricted,允许部门:人力资源部;当前身份:财务部)`

## 四、增强 C:审计日志

### 4.1 能力

- **留痕范围**:问答(`ask`)、冲突告警(`conflict`)、越权拒绝(`deny`)、文档新增/更新/删除/属性修改(`doc_add`/`doc_update`/`doc_delete`/`doc_meta`)、建库/库设置/删库(`kb_create`/`kb_update`/`kb_delete`);
- **记录内容**:时间、操作类型、操作者角色与部门、目标知识库/文档、结果、JSON 明细(如问答的问题与冲突数、文档更新的复用率等);
- **查询接口**:`GET /api/audit?action=&kb_id=&dept=&result=&limit=`;`GET /api/audit/stats` 统计;
- **可见范围约束**:非管理员仅能查询本部门记录;
- **前端审计页**:可按操作类型筛选、查看统计卡片与明细表。

### 4.2 实测证据

| 验证项 | 实测结果 |
|---|---|
| 审计记录总数 | 612 |
| 覆盖的操作类型 | ask、conflict、deny、doc_add、doc_delete、doc_meta、doc_update、kb_create、kb_delete |
| 越权拒绝记录 | 6 |
| 按类型过滤查询 | 可用(如 action=deny) |
| 统计接口 | 可用(总数/越权数/操作分布/最近时间) |
| 非管理员查询范围 | 仅本部门(实测 depts={'财务部'}) |

## 六、本次同时修复的问题

| 问题 | 影响 | 修复 |
|---|---|---|
| 制度元数据以表单字段上传但后端按查询参数接收 | 编号/生效期等字段丢失,版本管理失效 | 改为 `Form` 参数接收 |
